# 保留同一人物的 HTML 欄位範圍

這一步只使用 CPU、已保存的 HTML 及本機 HTTP 替身，沒有啟動模型、GPU、瀏覽器或公開網路請求。

## 實際修正

已曝光的球員題目中，SoccerStats247 的姓名、國籍及出生日期其實位於同一個 HTML 容器，每一列有兩個 span，分別顯示標籤與值。原解析器把每列拆成獨立普通段落，完整姓名無法取得同範圍的出生年份佐證。

新解析器保留這種重複的欄位結構，產生共同資料範圍及每個欄位的 literal value。它不依賴網站名稱、CSS class、球員姓名或標準答案。來源中的姓名重音與日期拼法保持原樣；冒號及 ` | ` 僅用來序列化實際標籤和值，與既有表格抽取相同。

辨識條件為同一 div 中有 2–12 個直接 div 子列，每列恰有兩個 span，沒有混雜文字、區塊內容或表單控制項。欄位標籤必須唯一，且恰有一個 Name 或 Full Name。標籤最多 70 字元／6 個詞，值最多 220 字元，完整範圍最多 1000 字元，每頁最多 80 組；超限、模糊或截斷來源不建立部分資料組。隱藏內容先沿用原流程移除。

每組只使用自己的欄位綁定。出生年問題仍必須有明確的出生日期／年份鍵，Country of Birth、Place of Birth 與 Last Updated 無法替代。沒有出生日期的組合不會擠掉原本能直接證明年份的傳記段落；未要求年份的問題仍可使用普通資料組。

## 證據與限制

[最終固定 42 個 CPU／HTTP 檢查](../benchmarks/field-groups-20261023-final.json)從 **23/42 到 42/42**，19 個改善、0 個退步。包含 33 個結構及欄位檢查、8 個本機 HTTP 流程、1 個原始網頁檢查。結構檢查也包含負例的預期資料組數量，不能把這 19 個改善寫成 19 題新增答對。

HTTP 替身只複製已有姓名並一律回覆 supported，隔離來源守門。兩個原本拒答的完整資料流程現在經 select、verify 得到姓名；五個日期不足或衝突的流程前後都拒答。帶有明確出生敘述的原始傳記流程前後都保留。這些不是實際模型成績。

相同三個原始來源及原始問題下，完整姓名與 `31/08/1988` 現在共同出現在排序第 **1** 的段落，完整進入前八段模型 payload；該 literal 姓名也通過必要的年份檢查。沒有重新執行模型，也沒有改寫答案別名或將此題補進任何十二題分數。

原本單獨的 inline 姓名段落依然缺少本地年份，仍不能借用其他段落。其回歸改為明確追蹤原段落，不再假設所有 Full Name 證據都缺日期；目前它仍在前八段的第 5 位。新資料組與舊 inline 段落各自驗證。

## 保存網頁與回歸

[最終解析語料重播](../benchmarks/field-groups-20261023-corpus-final.json)核對 22 份 capture 的 SHA256 及無省略記錄，再比較 68 份依 URL／body SHA 去重的非搜尋 HTML 回應。所有原有段落、連結、錯誤及截斷狀態都保持一致。新增資料組只出現在同一球員頁的兩個不同回應版本，不是兩個獨立網站。

[最終驗證清單](../benchmarks/field-groups-20261023-verification.json)記錄實際命令、程式及輸出 SHA256：代表性解析 15/15、組合證據 27/27、出生欄位 51/51、inline 欄位 19/19、資料範圍 11/11、Oyez 控制 24/24 與 HTTP 4/4、年份 41/41、首行結構 22/22，全部保持通過。完整回歸輸出保留在本機 research 目錄。

早期 37、40 及 42 個檢查的報告保留為迭代紀錄；最終範圍與比較以 final 報告為準。這個辨識器不涵蓋所有人物版型，新的模型與公開網路完整答題表現仍未驗證。

# Abstention and confidence evidence

The engine's abstention policy combines explicit model refusal, independent semantic rejection, literal/type/source checks, technical field binding, currency/date/version constraints and unresolved-conflict rejection. Deterministic acceptance uses a 5.5 alignment score; definitive adapters require 6.5 before early acceptance, and early deterministic navigation exit requires 8.0. These are development-tuned alignment thresholds, not probability thresholds. Known synthetic negative cases inform this policy; their later perfect abstention results are regression evidence.

The reported confidence is the unchanged heuristic `min(0.97,0.55+max(0,score)*0.025)`, rounded to three decimals. It is **not a calibrated probability**. Minimal evaluator output omits it; the compatibility profile and traces may expose it. An independent semantic check uses the same underlying model and is not independent statistical evidence.

`eval/calibration.py` computes answered-only Brier error, ten-bin expected calibration error and fixed selective-risk curves against exact joint answer/source correctness. Older harness rows reconstruct the documented confidence mapping from recorded selection scores; the report labels this reconstruction. An empty answer receives no correctness probability. No gold answer, production threshold or result is changed.

The [initial diagnostic](../benchmarks/confidence-audit-initial.json) shows why synthetic success is insufficient. The audited2 development set has 168 nonempty answers, all jointly correct, and ECE 0.0524. The first external 100 has 42 nonempty answers but only 5 jointly correct: Brier 0.6008, ECE 0.6987. Raising the confidence threshold to 0.9 retains 10 answers with 20% joint precision; 0.95 retains 2, both wrong. A higher threshold does not reliably recover correctness. Source availability, semantic alignment and answer formatting must improve; a cosmetic threshold change cannot certify 95% accuracy.

The new frozen external 100 scored 4% exact joint with 50 nonempty answers. Its directly recorded confidence has Brier 0.6052 and ECE 0.7213. At a 0.9 threshold all six retained answers are jointly wrong. The report is not reused to fit a threshold and then called an untouched holdout. Reliable general-web probability calibration remains unestablished and is an explicit readiness limitation.
